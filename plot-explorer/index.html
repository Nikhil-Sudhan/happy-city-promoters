SITE SETTINGS

Put your layout on the map.

Enter the coordinates of the centre of your site. Plot positions use metre offsets from this point, with north at the top.

A billing-enabled Google Cloud project and the Maps JavaScript API are required. Restrict your browser key to your site’s domain. The key stays in memory for this session and is excluded from exports.

Editing is a local planning tool, without authentication or shared storage. A production admin service is needed for multi-user management.
